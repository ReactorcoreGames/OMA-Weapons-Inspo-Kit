# Provenance (private, never shipped)

Maps every kit entry back to the source class it was derived from, and records each judgement call, estimate and invented value, so numbers can be re-checked against `sources/` later. The kit itself never names its sources.

| File | What |
|---|---|
| `weapons.yaml` | kit id → source class, package, layout per variant, notes |
| `name-blocklist.txt` | source names the validator flags inside `kit/` (generated by `tools/kit/build_blocklist.py`) |

Conventions in `weapons.yaml`: `layouts` maps each kit id (base and variants) to the source layout name. `derived` lists numbers taken from the canonical set (`bw_kit_units.json`) with their merge origin when it matters; `estimated` lists numbers that don't exist in the scripts (reload and cock times come from animations); `invented` lists kit-standard values with no source equivalent; `changed` lists deliberate departures from the source with the reason; `review` lists points to raise with the author.
